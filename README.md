# Hello Angular (Minimal)
//
This is a minimal Angular "Hello World" application scaffold.

Prerequisites
- Node.js and npm installed
- (Optional) Angular CLI installed globally: `npm i -g @angular/cli`

Install and run

```bash
cd "C:/Angular Project"
npm install
npx ng serve --open
```

Notes
- This project is a minimal scaffold. Running `npm install` will install Angular packages and the CLI tools.
